# Samsun Üniversitesi Anket Sistemi — Frontend

React + TypeScript + Vite ile geliştirilmiş SPA. Projenin genel açıklaması, kurulum adımları ve API dokümantasyonu için repo kökündeki [`README.md`](../README.md) dosyasına bakın.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

`.env` dosyası için `.env.example`'a bakın (`VITE_API_URL`, `VITE_CLERK_PUBLISHABLE_KEY`).
